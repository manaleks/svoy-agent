# Проверка служб перед нативным циклом

Запрос владельца — доказать установку, обновление и откат без потери состояния. После упаковки выполняется соответствующий контракт: Unix остановка и checkpoint на Mac/Linux, PowerShell-контракт на Windows. Файл выбирается явно, без платформенного пропуска. Предел каждой проверки 30 секунд, один worker. Вывод остаётся в закрытом временном каталоге раннера. При отказе нативный цикл не начинается. Публичный фильтр, разрешения и состав отчёта не меняются.

Проверка конфигурации — YAML и PowerShell-синтаксис. Доказательство исполнения — новый неизменяемый запуск трёх систем после принятого исходного коммита. Откат — предыдущая версия workflow.
